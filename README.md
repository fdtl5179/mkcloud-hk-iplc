## 三、共享 288 元起 vs 独享 650 元起，服务边界不一样

mkcloud 沪港 IPLC 的月付门槛差异不大，但两种计费的承诺范围完全不同。下单之前最好先想清楚自己的业务节奏，而不是先看价格。

### 共享带宽（流量计费）：峰值高、流量有上限，价格便宜

共享带宽的 1TB 套餐只要 ¥288/月，但官方明确写明 "共享带宽为峰值，不保证持续跑满"。这意味着：

- **峰值**：同机房其他用户空闲时，你能短期跑到 200M 也不是没可能，但 24 小时持续如此不在承诺范围。
- **流量**：上下行双向计算，超量后 VPS 会暂停使用，可自助购买流量重置包，也可申请工单补差价升级到更高流量档位。
- **不保证持久速率**：共享带宽的本质是忙时不独占、空时能跑上峰，所以你不能拿这带宽去跑需要稳定 24 小时满速的活。

共享版本适合的典型场景：白天偶发上传、批量更新素材、办公对港访问、有清晰月度流量预算的业务。

### 独享带宽（带宽计费）：速率稳定、流量无限，价格翻倍以上

mkcloud 沪港 IPLC 的独享版本从 5M/650 元起步，到 100M/7500 元。独享版本的核心承诺是：你的带宽值就是你的带宽值，不被其他用户分流。

- **独享不等于平台安全**：mkcloud 知识库明确写明，独享不代表任意目标都能跑满，也不代表平台账户安全或业务永不中断。

## 四、21ms 延迟能直接信吗？怎么测才算数

mkcloud 沪港 IPLC 官网资料里列的 21ms 是端内参考值，从 mkcloud 入口到香港出口之间这段专线的基线延迟，并不是用户本地到入口、本地到目标网站的端到端耗时。

真正影响速度的链路有四段：

1. 本地宽带或办公网络到 mkcloud 上海入口的延迟
2. mkcloud 入口到 mkcloud 香港出口之间的专线延迟（这就是 21ms 的部分）
3. 香港出口到目标平台网站的延迟
4. 目标服务器和本地 VPS 的实际负载

所以测速要分两段测，而不是只看一个数字。mkcloud 在帮助文档里专门写过《专线测速自测》一文，思路基本一致：你需要用 `ping` / `tcping` 从你的机器先 ping 入口 IP，再在你的 VPS 内 ping 目标服务器，两段都记录下来，才能知道瓶颈在哪一段。

另外有两点要记住：

- **21ms 不是 SLA**：21ms 是参考延迟，mkcloud 没把它写成 "包年可用率" 之类的承诺。
- **共享带宽套餐的 200M 峰值，不等于用户本地测到的下载速度**：本地还有上行速率、协议开销、目标限速、加密层开销。
